# Diseño de Euthyna (prototipo)

**Todas las cifras, votaciones y nombres de grupos de esta carpeta son inventados.** Sirven solo para probar el diseño y no describen la actividad real del Congreso. Los datos reales están en `datos/`, que generan los scripts.

- `index.html`: la página entera (cinco secciones). Doble clic para verla; no necesita conexión a internet.
- `estilos.css`: el aspecto visual. La paleta está al principio.
- `app.js`: pestañas, filtros y apariciones suaves.
- `fuentes/`: la letra Inter, servida desde aquí (no se pide a ningún servidor externo) con su licencia SIL OFL 1.1.
- `datos-inventados/`: los CSV de prueba que se usaron para escribir la página. La página no los lee: sus cifras están ya escritas en `index.html`.

Código bajo AGPL 3.0, como el resto del repositorio.
